# Restaurant POS Application (`apps/pos-app`)

React Native client application targeting tablets and captain handheld devices for tableside ordering, floor management, KOT firing, and billing.

## Development

```bash
# Run metro bundler
pnpm --filter @restaurant-erp/pos-app start

# Run Android
pnpm --filter @restaurant-erp/pos-app android

# Run iOS
pnpm --filter @restaurant-erp/pos-app ios
```
