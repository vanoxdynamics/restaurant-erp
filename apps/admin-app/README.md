# Restaurant Admin Application (`apps/admin-app`)

React Native client application targeting owner and manager smartphones for live KPI dashboards, End-of-Day (EOD) reports, menu item "86" toggling, and audit tracking.

## Development

```bash
# Run metro bundler
pnpm --filter @restaurant-erp/admin-app start

# Run Android
pnpm --filter @restaurant-erp/admin-app android

# Run iOS
pnpm --filter @restaurant-erp/admin-app ios
```
